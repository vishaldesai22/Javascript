# JavaScript Programming Examples

This repository contains a collection of **JavaScript programs** organized into folders by topic.  
It is aimed at beginners who want to learn JavaScript fundamentals with practical examples.

---

## 📂 Folder Structure

### 🔹 Basics of JavaScript
- Introduction to JavaScript syntax
- Variables, Data types, Operators
- Control statements (`if`, `switch`, loops)

### 🔹 Array and Functions
- Array creation, methods (`push`, `pop`, `splice`, etc.)
- Iterating arrays
- Functions: declaration, expression, arrow functions

### 🔹 Animation, Cookie, Webpages
- Simple webpage animations using JavaScript
- Cookie handling (`document.cookie`)
- DOM manipulation for webpages

### 🔹 Regular Expression and Validation
- Form validation examples
- Regular expression usage (`RegExp`, `test`, `match`)
- Client-side input checking

---

## 🚀 How to Run
1. Open the `.html` file containing the JavaScript code in any browser.  
   (JavaScript is embedded inside `<script>` tags or linked as `.js` files.)
2. Use browser **Developer Tools (F12)** → Console to view outputs.

- Regular expressions & form validation
